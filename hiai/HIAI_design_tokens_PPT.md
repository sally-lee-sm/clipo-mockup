## 3. 타이포그래피 (PPT 16:9 1920×1080 기준)

| 용도 | 사이즈 | Weight | 비고 |
|------|--------|--------|------|
| 표지 메인 타이틀 | 56pt | Bold | 1슬라이드 1회 |
| 섹션 헤더 | 40pt | Bold | 챕터 구분 |
| 슬라이드 제목 | 28pt | Bold | 매 슬라이드 상단 |
| 소제목 | 24pt | Bold | 콘텐츠 내 그룹 헤더 |
| 강조 본문 | 20pt | Bold | 핵심 메시지 |
| 본문 | 18pt | Regular | 기본 텍스트 |

> ⚠️ **본문 최소 18pt** — 발표 환경 가시성 확보. 14pt는 캡션/각주에만.
> 줄간격: compact(125%) = 한줄 라벨 / 일반(155%) = 여러줄 문장

## 4. 시각 스타일

### Border Radius
- 4px: 작은 태그·뱃지
- 8px: 버튼·인풋
- 12px: 카드·모달
- 24px: 큰 컨테이너·hero 영역
- 100px (pill): 상태 뱃지

### Shadow
- 기본: `0 4px 12px rgba(95,102,178,0.16)` ← 부드러운 보라톤
- 강조: `0 8px 32px rgba(95,102,178,0.16)`

### 버튼
| 종류 | 배경 | 텍스트 | 보더 | 용도 |
|------|------|--------|------|------|
| Primary | `#7E44FB` | white | — | 주요 CTA (슬라이드당 1개) |
| Secondary | white | `#7E44FB` | `#B28FFD` | 보조 액션 |
| Outline | white | `#494949` | `#D9D9D9` | 취소·일반 |
| Danger | `#DB3E51` | white | — | 삭제·위험 |

- 높이: 36px / Radius: 8px / Padding: 0 16px / Gap(아이콘-텍스트): 8px

### 뱃지 (pill)
- Radius: 100px / Padding: 2~4px 8~12px / Font: 12~14px
- 패턴: `옅은 배경 + 진한 텍스트` (예: `#F7F4FF` bg + `#7E44FB` text)

## 5. 톤 & 무드

- **B2B SaaS** — 신뢰감, 정돈됨, 차분한 보라톤
- **교사 친화** — 차갑지 않고 부드러움 (라운드 처리, 옅은 보라 활용)
- **AI 서비스감** — 보라 그라디언트 헤더 (`#7E44FB` → `#B28FFD` 또는 `#341761` → `#7E44FB`)
- 과한 채도·네온 금지
- 그라디언트는 보라 계열 1축만 사용

---

## 6. PPT 특화 활용 가이드

### 컬러 사용 비율 (60-30-10)
- 60%: 흰색·옅은 회색 배경
- 30%: 보라 계열 (`#341761`, `#7E44FB`, `#F7F4FF`)
- 10%: Semantic 색상 (그래프·뱃지·액센트)

### 슬라이드 유형별 컬러
| 유형 | 배경 | 강조 |
|------|------|------|
| 표지 | 보라 그라디언트 (`#341761`→`#7E44FB`) | 흰 텍스트 |
| 섹션 구분 | 보라 솔리드 또는 옅은 보라 | 흰/짙은 보라 텍스트 |
| 일반 콘텐츠 | 흰색 | 보라 포인트 |
| 다이어그램 | 흰색 | 보라 메인 + 회색 보조 + Semantic 1~2 액센트 |

### 일정 슬라이드 (간트차트)
- 메인 막대: `#7E44FB`
- 진행중: `#B28FFD`
- 완료: `#00AF3D`
- 예정: `#D9D9D9`

### 화면 목업 슬라이드
- 위 토큰 그대로 적용 (실제 서비스와 동일한 비주얼 유지)
- 브라우저 프레임 스타일 (회색 헤더 + dot 3개) 활용 가능
- GNB 영역: 흰 배경 + `#D9D9D9` 하단 보더 + 보라 로고
