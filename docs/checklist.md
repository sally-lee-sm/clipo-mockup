# 출고 전 체크리스트 — "올립이 만든 것처럼" 만드는 마지막 관문

> 화면을 "다 됐다"고 하기 **직전에** 한 줄씩 자가 점검한다.
> 이어받은 결과물이 어색해 보이는 건 대개 큰 게 아니라 아래 미세한 데서 티가 난다.

## A. 표기·문구
- [ ] **CLIPO / HIAI 전부 대문자?** (HiAI·Clipo·hiai 등 혼합·소문자 금지)
- [ ] **버튼 레이블 단어형?** "저장"·"추가"·"삭제" (O) / "저장하기"·"추가하기" (X)
- [ ] **같은 그룹 라벨 어미 통일?**(명사형이면 전부 명사형 — 평행성) 한 개 고쳤으면 그룹 전체 재검사
- [ ] **문구 맞춤법·띄어쓰기·조사 교정**했나 (받은 문구 그대로 붙이지 않기)
- [ ] **같은 화면에서 같은 메시지 두 번** 쓰지 않았나 (문구 역할 분리)

## B. 타이포·정렬
- [ ] 본문 **16px** / 레이블 **14px** 이상? (읽고 수정하는 본문은 반드시 16px↑)
- [ ] 카드 타이틀 20px / 페이지 타이틀 26px?
- [ ] **버튼 콘텐츠 중앙정렬 5종 세트**(inline-flex·align-items·justify-content·line-height:1·vertical-align) 들어갔나
- [ ] 표·grid 셀 **가로 중앙 정렬**?

## C. 색·박스
- [ ] **Alert/Info/Warning 박스에 좌측 컬러 띠(`border-left`) 없음?** (배경+아이콘만)
- [ ] 색을 "의미"로만 썼나 (장식용 색 남발 금지)
- [ ] 서비스 토큰 맞나 — CLIPO Primary `#416bff`·Pretendard GOV / HIAI Primary `#7E44FB`·NanumSquareRound

## D. 일관성·구조
- [ ] 헤더·좌측 NB·탭 밴드·푸터를 **새로 짜지 않고 레퍼런스화면에서 복제**했나
- [ ] **탭/세그먼트 활성 시 `font-weight` 변화 없음?** (색+밑줄로만 — 들썩임 방지)
- [ ] 공유 컴포넌트(반복 모달 등)가 페이지 간 1:1 동일한가
- [ ] 콘텐츠 폭 표준 지켰나 (CLIPO 수업 화면 = 1240px)

## E. UX 흐름
- [ ] 핵심 입력·선택을 **팝업으로 길막지 않았나** (인라인/페이지 전환 우선)
- [ ] 조작 컨트롤은 영향 필드 **뒤**, 설명·잠금·경고 안내는 영향 필드 **앞/상단**에 뒀나
- [ ] 행동유도가 **이점 먼저**인가 (강요·압박 톤 아님), 결과는 토스트로 즉각 피드백
- [ ] 개인정보 안내가 불안 유발("어디로 넘어간다") 아니라 "보호된다 + 화면엔 그대로 보여요" 톤인가

## F. 데이터·영향범위
- [ ] **가짜 반/학생 안 끼웠나** (실제 학급·학생 구성 안에서 상태만 변경)
- [ ] 라벨·패턴을 바꿨다면 **grep 전수 검사**로 같은 패턴 다른 화면도 동기화했나
- [ ] 메인 파일 ↔ `_annotated/` 동일 변경 반영했나

## G. 마무리
- [ ] 파비콘 태그 포함했나
